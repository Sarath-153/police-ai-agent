# **App Name**: NCRP Insights

## Core Features:

- Data Ingestion: Automatically import NCRP complaint data from various sources like CSV, Excel, and PDF files.
- Data Organization: Categorize complaint data into predefined columns: Complaint ID, Date, Complainant Details, Crime Type, Platform, Amount Lost, and Current Status.
- Data Deduplication: Tool to intelligently check for duplicate entries using complainant details and complaint type using AI.
- Google Sheet Export: Automatically update data in a Google Sheet, appending new complaints while removing duplicate entries.
- Real-time Dashboard: Display key complaint statistics on a real-time dashboard, such as the number of new complaints, types of cybercrimes reported, platforms involved, and amounts lost. Users can apply filters based on time, complaint type or platform to slice the statistics to the needs of various investigations.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and security.
- Background color: Light gray (#F0F0F0) to provide a clean and professional feel.
- Accent color: Teal (#009688) to highlight key data points and interactive elements.
- Body and headline font: 'Inter', a sans-serif font for clear readability and modern design.
- Use clear, universally recognizable icons for complaint categories and platforms.
- Emphasize key information such as complaint IDs and amounts lost.
- Use subtle animations to visualize changes in complaint status, for example, from 'registered' to 'FIR filed'.
